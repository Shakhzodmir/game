Цель. Первая партия расширения: уровни 101–200 и районы 6–10 (пять новых). Проверяет, что WP-13 работает на деле.

Слова продюсера: «Уровней будет только больше; не ограничиваться 100». Концерт в конце каждого района (`docs/handoff/WP-14.md`).

Контекст. `content/levels/README.md` (как устроены уровни, таблица кривой сложности), `tools/levels.lua`, `tools/bot`, валидатор `--strict`, `docs/handoff/levels-lead.md` и `levels-86-100.md` (как писались прежние), `docs/handoff/WP-13.md` (как добавить партию), `content/districts.json` (пять районов как образец: жанр, bpm, тональность, задачи, сундук, песни), `client/i18n_songbook.lua`, `tools/art/districts.py` (заглушки арта комнат), `docs/art-brief-chatgpt.md` (бриф комнат, раздел B1).

Что сделать
1. Уровни 101–200: кривая сложности продолжается (повторное введение механик, новые сочетания, пик к концерту района); каждый 20-й концертный. Приёмка по ботам как у уровней 41–100 (`tools/bot`, валидатор `--strict`, доли побед в записке). Новые механики не вводить без согласования; только новые раскладки и сочетания.
2. Районы 6–10: по образцу `content/districts.json` (идентификаторы, названия ru/en/ko, жанры, bpm, тональность, 6 задач с ценой, сундук, цвета); жанры берутся из уже существующего каталога жанров или новые по согласованию (`content/genres.json`); музыка через существующий генератор стемов (WP-6).
3. Песня-блокнот для каждого нового района: пул строк и названий на ru, en, ko по образцу `client/i18n_songbook.lua`; корейский читает носитель (пометь в записке).
4. Арт новых комнат: процедурные заглушки (`tools/art/districts.py`), имена картинок по правилу брифа; **добавь в `docs/art-brief-chatgpt.md` строки для 5 новых комнат** и запусти `python3 tools/art/import_incoming.py status` (картинок продюсера пока нет, заглушки остаются).
5. Карта, звёзды, пороги очков (`tools/stars.lua`), `map.json` (`tools/gen_map.py`) пересобираются из данных; `tools/check_content.lua` зелёный.
6. Проверка: прогон через мету от 1 до 200, проверка в браузере (карта на 200 узлах, комнаты нового района, блокнот).
Нельзя: менять уровни 1–100, формат сохранения (кроме новых полей верхнего уровня), правила матчей.
Готово: записка `docs/handoff/WP-17.md` (таблица кривой, доли побед, список новых текстов для проверки носителями, что нужно от продюсера: картинки комнат 6–10 по брифу); вопросы продюсеру.
