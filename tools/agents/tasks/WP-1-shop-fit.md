Цель. В магазине содержимое выходит за нижнюю кромку окна и экрана: карточка «Пополнить жизни» оказывается ниже белой панели и обрезана. Продюсер смотрит на широком экране 1920×970 (игра масштабируется по высоте).

Причина (проверь по коду). `gui/shop.lua`: окно фиксированной высоты (`local W, H = 680, 1150`), карточки по сетке `CARD_H = 214, CARD_STEP = 226`; бустеров стало 8 (добавился Кроссфейдер) плюс карточка жизней, строк больше, чем помещается. Окно итогов этот класс дефектов уже лечит через `fit_window` (`client/layout.lua`, `gui/result.lua`, тесты `tests/client/layout_test.lua`).

Исправь самым простым и надёжным способом: либо компактная сетка (карточка ниже, шаг меньше) с переходом на прокрутку, когда не помещается, либо закреплённая нижняя полоса для «Пополнить жизни» и прокручиваемый список бустеров.
