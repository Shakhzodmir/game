# План v3: от просьб продюсера 03.11.2026 к следующей версии

Состояние на 03.11.2026. Источник: сообщение продюсера и скриншот магазина. План рассчитан на работу «рабочими» на API-ключе продюсера (`tools/agents/`), по одной задаче за раз, каждая задача заканчивается проверенной веткой, потом PR, CI и живой сборкой. Продюсер может сказать «всё» в любой момент: игра после каждой слитой задачи рабочая.

## 3. Правила на всё время работ

1. **Прогресс игрока не уменьшается.** Формат сохранения расширяется только новыми полями верхнего уровня (шапка `meta/save.lua`); `save_io.APP_ID`, имена файлов и существующие поля неприкосновенны; сохранение лежит в браузере по происхождению сайта (`https://shakhzodmir.github.io`): другой компьютер, браузер или очистка данных сайта дают пустое сохранение, поэтому WP-0 делает код сохранения, а WP-10 облако.
2. **Каждая слитая задача проверена** тестами на обеих ВМ, линтерами и, где тронут экран, настоящим браузером (`tools/qa/web_screens.mjs`, снимки смотрит оркестратор). Рабочему не верим на слово: runner гоняет проверки сам.
3. **Публикация идёт при слиянии в основную ветку** (CI собирает и выкладывает на GitHub Pages). Продюсер играет на живом сайте, поэтому рискованное сначала проходит PR и CI, а новые возможности, меняющие игру (бонус-шкала, звёзды), имеют константы-переключатели.
4. Тексты ru, en и ko (после WP-3) в одном файле `client/i18n.lua`; инструмент WP-2 ловит вылезание текста на всех языках.
5. Реальные песни не используются: музыка и арт генерируются нашим кодом или присылаются продюсером; внешние шрифты только с открытой лицензией.

## 4. Что нужно от продюсера

- **Сейчас:** ключ API в окружении под именем `WORKER_API_KEY` (инструкция в `tools/agents/README.md`), лимит расходов в Console; разрешение пушить ветки `agent/*` (иначе работа живёт в контейнере, пока он не освобождён).
- **Арт:** бриф готов (`docs/art-brief-chatgpt.md`): один главный промпт, список из 58 картинок (очередь A 39, очередь B 19), листы-образцы в `docs/media/art-reference/`. Рисовать по группам в ChatGPT и присылать мне; после WP-8 скрипт `tools/art/import_incoming.py` вырезает фон, режет листы и подключает; до тех пор игра использует процедурные заглушки.
- **Для аккаунтов (WP-10):** создать проект у провайдера, включить входы, добавить домен сайта, положить публичный конфиг (подробная инструкция придёт в записке WP-10).
- **Решения:** на что тратить суперзвёзды; какие уровни концертные; очки бонус-шкалы за создание или срабатывание спецфишки; открывать ли все жанры джукбокса сразу (сейчас по районам); награды недели в чарте.
- **Проверка на втором компьютере:** после WP-0 перенести прогресс кодом сохранения, а не полагаться на браузер.

## 5. Ответы на вопросы продюсера

- **Что будет на 100-м уровне и после.** Сейчас мета переходит в состояние `all_done`: окно итогов последнего уровня и город показывают «Скоро новые уровни!», новых уровней нет. Тупиков и падений это не даёт, но выбора пройденных уровней может не быть; WP-0 проверяет сценарий 99 → 100 → после, исправляет дыры и описывает, что видит игрок. Новые уровни (101–120, шестой район) запланированы в `docs/plan-v2.md` (раздел 7).
- **Не пропадёт ли процесс при обновлениях.** Обновления сборки сохранение не трогают, пока не меняются `APP_ID`, файлы и поля (WP-0 ставит тест-замок). Пропасть оно может при очистке данных сайта, смене браузера или компьютера: для этого код сохранения (WP-0) и аккаунты (WP-10).
- **Почему отдельный ключ.** Ключ нужен, чтобы тяжёлая работа шла на оплате за токены, а не на тарифе сессии; рабочие используют только его.

## 6. Риски

- **Расходы.** Потолки задач сейчас на волнах 0–1 в сумме около 100 долларов, запуск по умолчанию останавливает новые задачи при 60 долларах расхода; фактическую цену первой задачи оркестратор сообщит сразу (`total_cost_usd` каждого рабочего).
- **Пересечение файлов.** Все задачи правят `client/i18n.lua`, HUD и меню; конфликты слияний решает оркестратор, сгенерированные файлы runner пересобирает сам.
- **Большие задачи (WP-7, WP-9, WP-10).** Могут не уложиться в потолок; тогда рабочий оставляет записку «что осталось», задача делится.
- **Внешние сервисы (WP-10, WP-11).** Без проекта у провайдера рабочий делает всё против мока; реальная проверка только после настройки продюсером.
