# Состояние проекта GLOW (пауза по просьбе продюсера)

Вторая пауза — 30.09.2026, по просьбе продюсера. Работа продолжится по команде «продолжай». Всё сделанное лежит в ветке `claude/brave-maxwell-j19fpr`. На момент паузы все тесты зелёные: 591 на Lua 5.1 и 591 на LuaJIT. Все 40 существующих уровней проходят валидатор ядра.

## Где остановились после возобновления 30.09
| Направление | Этап на момент остановки | Как продолжить |
|---|---|---|
| Ядро (`core/`) | этап B (спецфишки и комбо) шёл второй раз, этап A готов | возобновить workflow ядра (`resumeFromRunId`): этап A берётся из кэша |
| Игровой экран | сборка мира поля Defold (`screens/level`, `client/level_*`, `client/fx.lua`) шла | перезапустить этапы «Board → HUD → Review → Fix»; уже написанное остаётся |
| Экраны меты | сборка шла | перезапустить «Build → Review → Fix» |
| Уровни 41–100 | дизайнеры 41–60 и 61–80 работали, файлы ещё не записаны | перезапустить дизайн 41–100, затем ревью всей сотни |
| Боты и подбор ходов (`tools/bot`) | сборка шла | перезапустить «Build → Review → Fix», потом подбор ходов всех уровней |

## Прервано на середине (что осталось)
1. **Ядро (`core/`).** Этап A (фундамент) готов, итоги — в `docs/handoff/core-stage-a.md`. Этап B (спецфишки) прерван. Осталось:
   - выбор цели Пташки и её полёт (§8.3, §9);
   - геометрия всех 10 комбо, превращения «Цвет X», Гранд-финал (§8.5);
   - затем этап C (проверка всех элементов по спецификации, тесты свойств, золотые реплеи), рецензия и исправления.
2. **Уровни (`content/levels`).** Черновики 1–40 есть, 41–100 не сделаны. Ещё не выполнены:
   - сквозная проверка ведущим дизайнером;
   - слияние `README_part*.md` и `tutorials_part*.json` в общие файлы.
3. **Экраны меты (город, окно старта, магазин, настройки, автомат).** Сборка прервана. Часть модулей уже написана (`client/rewards.lua`, `client/popups.lua` и др.), их нужно проверить и доделать.
4. **Игровой экран (поле, анимации, звук, HUD).** Чистые модули готовы: `client/level_*.lua` с тестами. Осталось:
   - мир Defold (`screens/level`);
   - HUD, окна, интеграция с метой, обучение.
5. **Не начаты:**
   - боты и автоподбор ходов (`tools/`);
   - подбор ходов для 100 уровней;
   - финальная проверка в браузере;
   - план v2.

## Как продолжить
- Порядок работ:
  1. доделать ядро (этапы B и C);
  2. игровой экран;
  3. экраны меты;
  4. уровни 41–100;
  5. боты и подбор ходов;
  6. финальная проверка.
- Без режима Ultracode каждую часть делает один агент плюс одна проверка — так дешевле и медленнее.
- Окружение для новой сессии нужно поставить заново: JDK 25, `bob.jar` 1.13.1, `lua5.1`, `luajit`, Python-пакеты `numpy pillow scipy soundfile fonttools`. Как собирать и запускать — в `README.md`.
- Игра в браузере: включить GitHub Pages для ветки `gh-pages` (Settings → Pages), после этого — https://shakhzodmir.github.io/game/
