# Подбор ходов ботом

Прогон: бот `greedy`, 300 партий на уровень (сиды игры и бота 1..300, общие для всех уровней), бюджет 120 ходов, 3 процесс(а) `luajit`, 0 с, ядро 3.1.0. Ходы записаны в файлы уровней (`--write`).

Коридоры доли побед с первой попытки (`levels-plan.md`): easy 85–95% (цель 90%), medium 60–75% (68%), hard 35–50% (42%), super_hard 20–30% (25%).
