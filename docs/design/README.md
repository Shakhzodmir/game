# Документы по проекту GLOW

Индекс документов. Правило старшинства: если документы расходятся, прав `decisions.md`; дальше — спецификация (`core-rules.md`, `meta-economy.md`), и только потом остальное. Если код и спецификация расходятся, это баг одного из них, и исправление фиксируется в обоих.

## Дизайн (`docs/design/`)

| Документ | О чём |
|---|---|
| `decisions.md` | журнал решений v2: ответы на вопросы плана v1, исправленные «дыры», переименования, глоссарий «имя ↔ id», объём сборки, уточнения правил v3 и v3.1; главный документ |
| `core-rules.md` | точная спецификация ядра v3.1: тики и единицы, формат уровня (JSON), случайность, ввод, матчи, удары, спецфишки и комбо, гравитация, события, реплеи, хеш и API; контракт для `core/`, ботов и клиента |
| `core-rules-triage.md` | история решений: разбор замечаний рецензентов к спецификации v3 и v3.1 (принято, изменено, отклонено и почему), на английском |
| `meta-economy.md` | мета и экономика как реализованы: ресурсы, награды, жизни, продолжения и реклама, бустеры, серия, районы, прогноз прохождения, сохранение и журнал экономики, API меты |
| `levels-plan.md` | план 100 уровней: «пила» сложности и коридоры побед, график появления элементов, правила хорошего уровня, файлы и обучение |
| `art-direction.md` | арт-дирекшн v2 (яркий солнечный фестиваль): принципы, палитра фишек, спецфишек, поля, фонов и интерфейса, маскот Бит |
| `client-architecture.md` | архитектура клиента на Defold 1.13.1: проект, экраны и переходы, уровень, звук и синестезия, мета-экраны, сервисы, QA-мост, память текстур, протокол сообщений, открытые вопросы |
