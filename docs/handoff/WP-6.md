# WP-6: музыка — одна песня за раз, песня у комнаты, 15 новых жанров

**Сделано**
- **Одна песня.** Аудит: все пути запуска (город, районы, джукбокс, уровень, концерт, возврат из фона, быстрые переключения) сходятся в сообщении `music` скрипта звука. Смена трека теперь только кроссфейд 0,8 с (равная мощность, `audio.TRACK_CROSSFADE`); не больше двух треков сразу (третий запрос обрывает уходящий), `stop_music` затухает, тот же трек с другими слоями не перезапускается (раньше любой переход резал звук). Статус для QA: `tracks`, `xfade`, `overlap`, `max_overlap`.
- **Комната — своя песня.** У каждого из 5 районов своя слоёная тема, играет при входе; выбор в джукбоксе главнее до «Вернуть музыку города» (так и было; добавлен тест на все комнаты).
- **15 жанров, 49 песен** (`content/genres.json`, код `tools/audio/songs_*.py`): классика, народная (кельтская и африканская), латино (танго, фламенко, кумбия, сальса), восточная — по 4; поп, хип-хоп, EDM, R&B, регги, кантри, блюз, босса-нова, эмбиент, кино-оркестр, чиптюн — по 3. Таблица — `WP-6-songs.md`. Только оригинальные композиции из кода, сид детерминирован (`dsp.rng`).
- **Окно джукбокса.** Вкладки жанров листаются по три стрелками (20 жанров), значок у каждого (`ui/genres/<id>`, процедурные заглушки `tools/art/genres.py`; бриф B3 дополнен именами). Строки песен без обрезки (проверка `G.overflows`, ru/en/ko, все размеры окон).
- **Переключатель** `meta/config.lua`: `C.genres_unlock = "districts"` (по умолчанию: жанр открывается с районом; в 1-м районе сразу Lo-fi, классика, народная, эмбиент) или `"all"` (все жанры сразу). Сменить строку и пересобрать; сохранённый `prefs.song` не стирается ни в одном режиме.

**Проверено.** `./tools/test.sh`: 2 прогона зелёные (см. итог ниже), новые тесты: `audio_xfade_test` (последовательности и случайный перебор 400 событий с проверкой инварианта в каждый кадр; мутация «не отпускать старую деку» ловится), `genres_test`, правки `songs_assets_test`, `meta_windows_test`. `gen_audio.py`: все проверки зелёные, +5,6 МБ ogg (лимит +8), 223 компонента из 256, бюджет песен поднят до 14 МБ. Новая проверка `gen_audio.py --preview id` для разработки песен и `--songs` для пересчёта нескольких.

**Не проверено.** Браузер: в `web_screens.mjs` добавлены проверки (`tracks ≤ 2`, `max_overlap ≤ 1,05 с`), но сборки `bob.jar` нет — не запускались. Музыку никто не слушал; щелчок возможен при трёх быстрых переключениях подряд (третий запрос обрывает уходящую песню на её текущей громкости). Прокрутка пальцем не сделана: страницы со стрелками (как у магазина WP-1 «сжатие вместо прокрутки»).

**Решения.** Жанры не районы (районы и прогресс не тронуты, формат сохранения не менялся). Две песни (`oasis_nights`, `silky_groove`) перенастроены под запас громкости уровня (`ceiling_trim`, бас выше, барабаны тише). Ниже 80 Гц проверка тональности не слышит, поэтому суббас у трэпа и EDM поднят.
