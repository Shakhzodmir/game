# WP-7: карта игры

**Что сделано.** Экран `map` (`screens/map/`): длинная вертикальная дорога из 100 уровней (5 районов по 20 уровней, у входа в район арка с названием, украшения по бокам). Узлы: закрыт (серый с замком), «текущий» (золотое кольцо, пульс, на нём стоит Бит), пройден (зелёный, под ним 1–3★ по рекорду, у концерта значок суперзвезды), концерт (крупнее, корона, свечение; концерты берутся из `content/levels/stars.json`: 60, 70, 80, 90, 100). Тропа из «камешков» (пройденная часть золотая). Прокрутка пальцем и колесом с инерцией, упор на концах, кнопка «К моему уровню», когда он вне экрана. Тап: по текущему — окно старта (`gui/start.lua`), по пройденному — то же окно в режиме повтора (рекорд, звёзды, «Играть снова»: тренировочный заход без монет и жизней, звёзды растут), по закрытому — подсказка «Откроется после уровня N». После победы с карты уровень возвращает на карту (кнопка «На карту»), Бит шагает по тропе к новому узлу, узел загорается. После 100-го: Бит на последнем узле, в конце дороги знак «Скоро новые уровни!».
**Вход из города.** Рядом с кнопкой «Уровень N» (она стала уже) появилась синяя кнопка «Карта» с иконкой; «Пройденные уровни» (после 100-го) остались, тоже уже. Выбор: быстрый вход «Уровень N» нужен тем, кто не хочет смотреть на карту; карта рядом, а не вместо.
**Сохранение не тронуто.** Прогресс карты считается из меты (`level_to_play`, `level_stars`); позиция Бита и прокрутка живут только в сессии (`screens/map/view.lua`, `remembered`), новых полей нет.
**Файлы.** `content/map.json` (пишет `tools/gen_map.py`, можно править руками; проверка `gen_map.py --check`), `client/map_model.lua` (модель: видимые узлы, состояния, тропа, нажатие), `client/map_scroll.lua` (прокрутка), `screens/map/{map.gui_script,view.lua,hud.lua}`, заглушки арта `tools/art/map_art.py`, иконка `ui/icons/map`, клавиши колеса в `input/game.input_binding`, QA-команда `map goto|tap <n>`.
**Формат `content/map.json`** (мир 720 px по x, y вверх от низа карты): `width`, `world_height`, `level_count`, `tile_h` (высота куска фона, 1080); `node.day|concert` = `{size, hit (радиус круга для нажатия), states{locked,open,current,done}}` (имена картинок); `path` = `{dot, dot_done, spacing, size}`; `bit` = `{size, dy}`; `soon.y` (знак после 100-го); `segments[]` = `{id, district, first, last, y0, y1, bg, gate, gate_y, sign{dx,dy,w} (где писать название на табличке, по умолчанию 0,116,280), tint, deco[{image,x,y,scale}]}`; `nodes[]` = `{level, x, y}`. Правила проверяет `map_model.validate` (узлы растут вверх, участки без дыр, все 100 уровней).
**Картинки, которые ждёт карта** (процедурные заглушки лежат в `assets/images/map`, `mapbg`; бриф `docs/art-brief-chatgpt.md`, группа A3, там добавлена таблица размеров; A3.6 изменён: вместо кусков дорожки два «камешка»): `mapbg/bg_<район>` 720×1080 (5), `mapbg/gate_<район>` 720×480 (5), `map/node_day_{locked,open,current,done}` 160×160, `map/node_concert_*` 224×224, `map/path_dot`, `path_dot_done` 48×48, `map/deco_<район>_<1..6>` 160×160 (30). Состояние `open` пока не используется (играть можно только следующий уровень), картинка в запасе.
**Как проверено.** Тесты: `map_model_test` (20: данные, видимость на каждом смещении, состояния, тропа, нажатие, физика прокрутки), `map_screen_test` (14 на строгой заглушке GUI: новый игрок, игрок на 89-м, старт с карты, закрытый узел, повтор, перетаскивание и колесо, шаг Бита, после 100-го, 5 размеров окна × ru/en/ko, число узлов и картинок); обезьяна и `check_refs` включают карту. В `tools/qa/web_screens.mjs` добавлен блок 1b3 (карта, прокрутка, тап по уровням, победа, Бит на следующем узле, снимки `client_map*.png`). **Браузерный прогон не запускался** (нет `bob.jar`/браузера в этой среде): вид карты глазами не проверен, только заглушкой.
**Решения.** Узлы и точки тропы пулируются (число узлов GUI держится в районе 350–600 при любой длине карты); фон режется на куски 720×1080 и зеркалится через один; шаг между уровнями 190 px (около 6 уровней на экран). `BUDGET_MB` арта поднят с 9 до 10 (карта добавила 1 МБ).
**Вопросы продюсеру.** 1) Нужен ли вход «Карта» вместо «Уровень N», а не рядом? 2) Районы по 20 уровней — подходит ли (концерты 60–100 не совпадают с границами районов)? 3) Хотите ли, чтобы Бит стоял на узле и после проигрыша/выхода без движения (сейчас да)? 4) Показывать ли на карте жизни и монеты (сейчас только звёзды и «Город»)?
