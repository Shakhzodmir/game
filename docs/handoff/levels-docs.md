## Решения
1. Уроки «по желанию» (41, 60, 66, 95, 100 — тап по подарочной спецфишке или два свапа) не включены: по плану уроки только у новых элементов, а на 41–100 игрок уже умеет тапать. Все пять проверены тестом на черновой копии файла (обе ВМ), в README лежит таблица, чтобы включить за минуту.
2. Колонка «ходы» в README — снимок на день сборки; после `tune.lua --write` числа нужно обновить руками (по `luajit tools/levels.lua stats`).
3. Список уровней с явными спавнерами взят из файлов и содержит 70 (в передаче ведущего его не было); блокеры на спавнерах: 46, 74, 76, 77, 78, 86.
