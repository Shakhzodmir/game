**Не сделано и почему.**
- **Присылать ID на почту нельзя без сервера**, в игре только текст. Как сделать: при регистрации писать в Firestore `profiles/{uid}` ID (правило «только владелец»; сейчас после привязки почты ID пропадает совсем), Cloudflare Worker (бесплатно) принимает почту + Turnstile, ищет аккаунт через Admin API по ключу в секретах Worker, шлёт письмо только на подтверждённую почту и всегда отвечает «если есть, отправили», с лимитом на IP и адрес. Облачная функция Firebase потребует тариф Blaze (карта).
- Не проверено: Safari и iPhone (блокировщик вкладок строже, тост на этот случай есть), вид самого письма (шаблон Firebase), `web_screens.mjs` целиком.

**Решения (мои).** ID-подсказка стоит текстом, а не кнопкой (места хватает). Страница политики выбирает язык по браузеру, а не по языку игры (кнопки RU/EN/KO сверху). Политика честно пишет то, что видно в коде: Firebase грузится с серверов Google **при каждом запуске, даже у гостя**; регион eur3 относится к Firestore, а данные входа обрабатывает Google по своим правилам; хостинг GitHub Pages видит IP. Корейский текст (кнопки, подсказки, страницы, форма) написал сам: нужна проверка носителем (политика в формальном стиле 합니다).

**Вопросы продюсеру.** 1) Контакт-страница issues публична: личный запрос на удаление там не подать. Нужна ли отдельная почта проекта (не личная)? 2) Возраст: «13 лет» временный; для Кореи порог согласия родителей 14, для части ЕС 16. 3) Грузить Firebase только при открытии окна входа (чтобы гость не обращался к Google)? Мелкая правка, но вход при запуске станет чуть медленнее. 4) В консоли Firebase, Authentication, Templates, «Password reset»: проверьте имя отправителя и текст письма (язык берётся из игры). 5) Адрес политики для экрана согласия Google и для магазинов: `https://shakhzodmir.github.io/game/privacy.html` (вписан в `WP-10-setup.md`, шаг 6).
