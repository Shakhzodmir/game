## Решения плана (предлагаю внести в `decisions.md`)
1. Порядок запуска: веб-порталы, затем Android вместе с RuStore, затем iOS.
2. **Звёзды:** уровни 101+ нельзя выпускать без новых районов (126★ против 124★ города); партия 101–120 выходит вместе с районом 6.
3. Реклама на порталах — только за награду, как в журнале; межстраничную рекламу не включаем (вопрос Q4 продюсеру).
4. Аналитика — PostHog по HTTP; облако, события и проверка реплеев на сервере — Nakama (спайк N1); remote config — свой JSON.
5. Ассеты тремя волнами A/B/C; бюджет с резервом 15 %: Т1 8,1–21,7, Т2 8,4–21,9, Т3 1,2–4,1 тыс. $; весь путь до глобального запуска 21–59 тыс. $.
6. Пакет `com.glow.encoretown` менять только до первой загрузки в магазин, поэтому проверка знака (8.1) идёт в Н1–4.
7. Пороги GO / FIX / NO-GO (6.3, 6.5) — гипотезы, утверждает продюсер до софт-лонча.
