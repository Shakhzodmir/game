## Рецепт: как добавить район части 2 (17–30)

Команды из корня репозитория, Windows + Git Bash (`export PATH="$PATH:<путь к LuaJIT>"` — путь LuaJIT у продюсера; на Linux `luajit` и `python3` уже в PATH). Район N, родитель — район N−15 части 1. Данные района берите из таблицы `docs/design/part2-districts.md`.

1. **Данные** (`content/districts.json`, в конец списка, по образцу `midnight_cafe`): `id`, `"part": 2`, `first`/`last` (20 уровней сразу после предыдущего), `map_tint`, `name`/`genre` на ru/en/ko, `bpm`, `key`, `semitones_from_c`, `bars` (8), `mood`; 4 песни (`id` уникальные во всём каталоге, `name` ru/en/ko, `bpm`, `bars`, `mood`); `chest`: монеты 3200 + 200 × (N − 16), три бустера; 6 задач с ценами **1, 4, 5, 5, 5, 6**, первая со стемом `beat`. Задачи пишите в том же порядке, что предметы родителя (i-й предмет заглушки берётся у i-й задачи родителя; иначе таблица `TASK_FROM` в скрипте заглушек). Новое имя стема — ключ `stem.<имя>` в `client/i18n.lua` (en, ru) и `client/i18n_ko.lua`. Коммит.
2. **Песенник**: `sb.<id>.1…32` и `sbt.<id>.1…16` в `client/i18n_songbook.lua` (en, ru; 1–8 слов, без чужих текстов) и в `client/i18n_ko.lua` (ko). Сюжет и тон — другие, чем у района-родителя. Файлы с CRLF: правьте так, чтобы концы строк не поменялись.
3. **Заглушки картинок**: `python tools/art/make_part2_placeholders.py <id>` (12 с), строку в `ROOMS` программы `tools/art/install_district.py` (места предметов родителя: `x`, `y` из `content/district_layouts.json`, ширина = `w × scale`), ночной район — в `M.NIGHT` файла `client/level_sky.lua`. Посмотреть картинки глазами (лист: комната, карта, ворота). Коммит.
4. **Музыка**: тема из слоёв в `tools/audio/music.py` (функция района + по функции на стем, 6 стемов задач + `tension` + `party`, регистрация в `DISTRICTS` и в таблицах, где есть `arcade`/`midnight_cafe`), 4 песни в `tools/audio/songs.py`, рендер только нового (КОМАНДА_РЕНДЕРА), цвет вкладки в конец `M.DISTRICT_COLORS` (`client/views.lua`). Все проверки `gen_audio.py` зелёные. Коммит.
5. **Уровни** N×20−19 … N×20: 20 файлов, пила района (`docs/design/part2-districts.md`, «Кривая»), `luajit tools/levels.lua validate --strict`; подбор `luajit tools/bot/tune.lua --jobs 1 --levels A-B --n 100 --work <папка>` в нескольких процессах по диапазонам (на Windows `--jobs` > 1 не работает), правка раскладок, финальный `--n 300 --write --md docs/levels/tuning_<A>_<B>.md --json ...`; `luajit tools/stars.lua gen` (записи 1…предыдущих не меняются), `luajit tools/stars.lua check --replay`; строки README `docs/levels/README.md`; в `tests/tools/levels_content_test.lua` и `stars_content_test.lua` — счётчики пилы района (по образцу района 16). Коммит.
6. **Карта и ресурсы**: `python tools/gen_map.py`, `python tools/gen_defold.py` (около 80 с; корейские шрифты), `PYTHONIOENCODING=utf-8 python tests/client/font_advances.py`. Коммит сгенерированного.
7. **Проверки**: `luajit tools/check_content.lua`, `luajit tools/check_refs.lua`, `luajit tools/levels.lua validate --strict`, `luajit tools/stars.lua check --replay`, `luajit tools/stars.lua gen` (без изменений), `python tools/gen_map.py --check`, полный `luajit tools/test/run.lua` (на Windows 30 падений в `tests/tools/*` cli, common, levels, readme, tune, write и `floor_art_test` — норма, новых быть не должно).
8. **Сборка и снимки**: `../GLOW-tools/jdk25/bin/java -jar ../GLOW-tools/bob.jar --platform wasm-web --architectures wasm-web --variant debug --archive --bundle-output dist resolve distclean build bundle` (около 90 с), `cd dist/GLOW && python -m http.server 8765`, `node ../GLOW-tools/p2shots.mjs http://localhost:8765/index.html <папка>` (сценарий вне git, рядом с `shots.mjs`: проходит мету до первого уровня района, листает город к району, снимает комнату днём и в концерте, автомат, ko/en, карту, первый и концертный уровень; поменять в нём номера и `id`). Смотреть: надпись на воротах, плашку района, предметы, тексты.
9. **Документы**: строка района в `docs/design/part2-districts.md` (что вышло), промпты C<N> в `docs/art-brief-chatgpt.md`, короткая записка.

Тесты, которые больше не требуют правки при новом районе: число районов, последний уровень, город (`tests/meta/config_test.lua`: район части 2 обязан стоить 26 и быть `part` 2), карта, блокнот, повтор после последнего уровня, небо уровня, проверки содержимого. Правки нужны только в тестах пилы уровней (`levels_content_test`, `stars_content_test`) — это сознательные «замки» экономики.

## На что наступали

- **CRLF.** У продюсера `core.autocrlf=true`: рабочие файлы с CRLF, а Python пишет LF. Скрипты, которые вставляют строки в `client/i18n*.lua`, должны читать с `newline=""` и писать теми же концами строк; иначе `str.count` не находит образец. После `gen_defold.py` двадцать сгенерированных файлов «изменены» только концами строк: `git checkout -- <файл>` или просто не коммитить их, если `git diff --stat` пуст.
- **`gen_art.py` целиком не работает с района 6** (нет процедурных предметов для районов из рисунков продюсера): заглушки части 2 делает отдельный скрипт, и они записаны в `installed.json`, чтобы `gen_art.py` их не трогал.
- **Табличка ворот.** `gate_signs.py` ищет бледную табличку; ночной фильтр сохраняет её цвет (маска таблички родителя), а место надписи копируется у родителя.
- **Новый стем** (`rain`) требует ключа `stem.rain` в i18n, иначе падает `tests/client/i18n_test.lua`.
- Пока музыки или уровней района нет, падают `check_refs` (нет стемов и песен) и `check_content` (нет файлов уровней и порогов): это ожидаемо между шагами рецепта.
