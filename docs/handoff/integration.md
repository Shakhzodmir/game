## Что есть
- **Линтер ссылок** `lua5.1 tools/check_refs.lua [--quiet] [--unused]` из корня, сейчас 0 проблем. Девять проверок: a require/циклы/не из tools и tests; b id картинок и анимаций атласа (в т.ч. семейства `pieces_`…); c звуки, ноты, стемы, компоненты `audio.go`; d i18n en+ru, семейства ключей; e темы шины (опубликована ↔ подписана, подписка закрывается; 5 исключений с причинами в шапке файла); f `msg.post` ↔ `on_message` целевого скрипта и ответы протокола; g пути из .gui/.collection/.go/.atlas/game.project/реестра/строк Lua, `.defignore`, прокси и действия ввода; h `module.member`, `obj:method(`, `meta:xxx(` (число аргументов, `now`); i контексты Defold (gui.* только в gui_script, go.*/sprite.*/factory.* только в .script, в скриптах глобальны только колбэки движка). `refs_test.lua` (17): репозиторий чист + по синтетическому нарушению на правило.
- **Сессионная обвязка** `session_harness.lua`: настоящие `app.script`, оверлей, `audio.script` и скрипты всех экранов в одном Lua-состоянии; эмулирует collection proxy (async_load → proxy_loaded → init/enable → final/unload, удаление объектов фабрик), порядок ввода движка (оверлей над экранами), соль игрока одинаковая на обеих ВМ (те же доски). Любая печать `WARNING:`/`ERROR:` и находка `E.audit()` (глиф вне шрифта, обводка на шрифте без неё) валит сессию, ожидаемую берёт `s:take_warnings(текст)`; QA-команды — `s:qa("goto town")` (из контекста app.script, как в движке).
- `session_test.lua` (20): сплэш → уровень 1 с обучением настоящими свайпами → победа → итоги → город (очередь наград, полёты, задача, стем) → район (концерт, сундук) → окно старта → Next level/Play → +5 ходов за монеты → сдаться → поражение → ретрай → 0 жизней → окно жизней → рефилл → магазин → настройки (язык при открытом окне в городе и на уровне, режим ввода, сброс) → фокус, ресайз → сбой записи; оверлей глотает касания под затемнением; не собравшийся уровень возвращает в город; холодный старт с диска убитого процесса (`s:files()` → `S.run{files=…}`): попытка после хода — поражение, до хода — отмена; язык и ввод переживают рестарт.
- `session_monkey_test.lua`: 6 сохранений × 300 случайных действий (кнопки из `app.ui.*targets`, касания, свайпы, Back, фокус, ресайз, язык, автоплей, сбой записи, скачки часов до 40 дней, прыжки QA-моста). Инварианты: ≤12 подписок, в городе ровно 3, попытка закрыта, награды показаны, шапка = мета. Вне набора: ≈150 сидов × 300–400 действий на обеих ВМ чисто.
- `session_levels_test.lua` (3): все 100 уровней собираются настоящими скриптами экрана и играют 2 хода; каждый 7-й помещается в окна 320×568, 1280×720, 1024×1366 с поворотом; каждый 20-й выигрывается до окна итогов. Падение называет уровень (и окно). Разово проверено 100 уровней × 5 окон.
- `qa_script_test.lua` (6): `web_screens.mjs` ↔ мост: команды существуют (`qa_bridge.has`), аргументы понятны, читаемые поля публикуются, кнопки отдаёт игра, окна цикла `open` открываются с тем же JSON.

## Найдено и исправлено
- `web_screens.mjs` отстал от кода: «Уровень N» теперь открывает окно старта (потом Play), первый запуск сразу в уровень 1, пауза нажималась по координатам, `const played` объявлена дважды (SyntaxError на весь скрипт). Теперь кнопки берутся из того, что публикует игра; добавлены цепочка победа → Next level → старт → Play → пауза → выход и окно `confirm`.
- Уровневый экран не публиковал кнопок: `app.ui.level.targets` (pause, stick, row_light, col_light, remix).
- **QA-команда `win` застревала** на любом уровне, где подсказки не хватает ходов: окно «Ходы» ставит сессию на паузу, автоплей не брал бесплатные +5. Найдено прогоном всех уровней (8 из 25); исправлено в `Session:autoplay_step`, тест в `level_session_test.lua`.
- Заглушка `town_defold_stub.lua`: `collections`, отправитель сообщений, `Object:final` снимает фокус ввода. В остальном клиент линтер и сессии дефектов не нашли.

## Проверено без правок
`gen_defold.py --check` чист; `check_syntax.sh` ok (обе ВМ); `game.project`: 3 прокси ≤ `collection_proxy.max_count` 16, все действия ввода из кода есть в `game.input_binding`, лимиты спрайтов/частиц/фабрик читают строгие заглушки (частицы ≤ 66 компонентов при 128); heap 256 МБ против ≈10 МБ атласов и ≈48 МБ картинок районов (по одному на экране, `release_images`); `.gitignore`/`.defignore` разумны.

## Решения (для decisions.md — вносит оркестратор)
1. Кнопки для QA публикует сам клиент (`app.ui.targets`, `popup_targets`, `level.targets`); скрипт координат не знает.
2. В сессионных тестах любая `WARNING:`/`ERROR:` строка — провал; ожидаемые объявляются явно.
3. Исключения линтера живут в шапке `tools/check_refs.lua`, каждое с причиной.

- В настоящем Defold не запускалось: `web_screens.mjs` проверен на согласованность с мостом, не на поведение (z-order, шейдеры, звук, GL, ввод через прокси). Первый прогон на сборке — обязателен.
