# Мета-экраны: город, окна, заставка, оверлей — передача

Файлы: `screens/town/*`, `screens/splash/*`, `gui/{start,shop,settings,lives,jukebox,concert,chest,gift,confirm,kit}.lua`, `client/{views,popups,meta_qa,flow,qa_bridge}.lua`, `client/services/*`, `main/{overlay.gui_script,app.script,audio.script}`, блок «META SCREENS» в `client/i18n.lua`. Тесты: `tests/client/meta_*`, `services_test`, `qa_bridge_test` (161 тест, обе ВМ).

## Что есть
- **Город:** сцена района (ghost → восстановлено), верхняя панель, карточка задачи, «Level N» с тегом Hard/Super Hard и тремя нотами серии, навигация (Группа/Чарт — «скоро»), день/концерт, концерт района → сундук → следующий район, подсказка `tutorial.town`. Листание районов стрелками и свайпом (`town.focus` — стройка, `town.district` — на экране).
- **Окна** (стек `client/popups.lua`): старт уровня, жизни, магазин (деньги «недоступны» в веб-демо; в debug — тестовые покупки и видео-подарок раз в минуту), настройки, джукбокс, подарки открытия, сундуки, концерт. Награды уровня (`client/rewards.lua`): очередь, полёты, счётчики = мета − очередь − удержанное; удержаны монеты, звёзды и **секунды безлимитных жизней сундука** (`town.hold.infinite`, `Hud:lives_view`).
- Оверлей: затемнения, тосты, модалки. Заставка ≤ 3 с. Язык пересобирает всё. Безопасные зоны; окна 720×1280, 1280×720, 390×844, 768×1024. В GPU только картинки района на экране.

## Как проверять без движка
- `tests/client/town_defold_stub.lua` — строгая заглушка GUI: настоящие скрипты, неверный вызов API или удалённый узел — ошибка; `E.audit()` ищет глифы вне шрифта, превышение `max_characters` и **обводку/тень на шрифте без неё** (`small`, `body`). Модель движка: `gui.set_inherit_alpha` (по умолчанию выкл., `E.opacity(node)`), **PINGPONG: `duration` — весь цикл туда-обратно** (gui.cpp 1.13.1). Шаблоны: `tests/client/meta_gui_helper.lua` (`G.with_town`), снимок экрана — `gui_snapshot.lua` + `.py`.
- Обезьяна `meta_monkey_test.lua` (4 сида в наборе; 82 доп. сида на обеих ВМ чисто). QA-мост: `client/meta_qa.lua`, `tools/qa/web_screens.mjs`; в состоянии моста теперь `app.analytics` (счётчик и 8 последних событий).

## Исправлено по ревизии (все — с тестом, падавшим до правки)
- Серия: закрытый слот (бустер ещё закрыт) — бледная нота с замком (`kit.note`), город, окно старта и итоги; до 12-го уровня — обычные пустые ноты; закрытая нота не «загорается» (`Hud:note_open`).
- `fx`: `pop` возвращает кнопку к её масштабу покоя (`ui.rest_scale`), `shake` двигает только x и помнит покой только пока трясётся, `bob`/`wiggle`/пульс концерта — период = полный цикл. Подпись/иконка кнопки наследуют альфу (`gui.set_inherit_alpha`).
- Тост «не удалось сохранить» — один на серию, даже если серия началась до оверлея; магазин не трогает узлы закрытого окна; слайдер завершает «потерянное» перетаскивание следующим нажатием; заголовок сундука района в две строки; очередь наград 128 (уровень выигрывается один раз, потолка хватает на всю игру).
- Аналитика: печать в debug, `session_end`/`session_start{resume}` (период на переднем плане), `ad_offer` магазина; `from` окна старта = экран-хозяин; списки бустеров/настроек берутся из `meta/config.lua`.

## Решения (для decisions.md — вносит оркестратор)
1. Район на экране и район стройки разделены; листание не пишет в сохранение. Кулдаун видео-подарка живёт в сервисе (сессия).
2. Слот серии, чей бустер ещё закрыт, показывается закрытым (замок на бледной ноте); до 12-го уровня серия не идёт и замков нет.
3. Безлимитные жизни сундука появляются на панели, когда долетело сердечко, как монеты и звёзды.
