# Игровой экран: HUD, окна, итоги, Бит, обучение

Состояние: готово к проверке в Defold. Сборки Defold в контейнере нет: весь GUI-код прогнан на строгой заглушке (`town_defold_stub.lua`) с настоящим ядром за поддельным полем (`tests/client/level_fake_board.lua`); HTML5-сборка проверяется в CI.

## Что где
- Чистая логика с тестами: `client/level_hud.lua` (раскладка, слот Бита, цели, ходы, прожектор, рука), `level_bit.lua` (настроение Бита), `level_windows.lua` (что говорят окна, числа только из меты), `level_end.lua` (конец попытки через мету), `tutorial.lua` (рантайм обучения), `level_link.lua` (мост к полю и охранник обучения).
- GUI-клей: `screens/level/level.gui_script` (шина, ввод, окна), `hud.lua` (верхний ряд, панель бустеров, Бит, полёты к целям, очки), `tutorial_view.lua` (затемнение, рука, пузырь).
- Окна `gui/`: `pause`, `moves`, `defeat`, `result`, `booster_buy`, общие детали в `level_kit.lua`; старт, жизни, магазин, настройки, подтверждение открываются из окон мета-агента.
- Проверки: `level_screen_test` (экран на заглушке: HUD, бустеры, пауза, выход, ходы, поражение, итоги, обучение, размеры, языки, обезьяна), `level_i18n_test`, `level_guard_board_test` (настоящий `board.script` с охранником), `tutorial_content_test` (все 15 авторских обучений на настоящих досках, оба режима ввода, без починок ядром), модульные тесты.
- Картинки без Defold: `lua5.1 tests/client/level_hud_snapshot.lua <сценарий> out.json [ru] [WxH]`, затем `python3 tests/client/gui_snapshot.py out.json out.png 0.6` (список сценариев в шапке).

## Как устроено
- Конец попытки: победа и поражение закрываются через `meta:finish_level`, выход из паузы до первого хода сбрасывает попытку без потерь, после хода это поражение. Окно паузы и «ходы закончились» честно называют потерю жизни и серии. Не вошедшие в поле бустеры (`unplaced`) возвращаются через `meta:grant("unplaced_refund")` и названы в итогах.
- Пауза закрыта, когда победа уже ясна (`won_wait`, `concert`, `complete`): выход из финала записал бы поражение за победу.
- Обучение читает `/content/tutorials.json`; пока его нет, в игре обучений нет (части лежат в `content/tutorials_part1/2.json`, тест читает их). Шаги идут через охранника в `level_link` (чужой ход не принимается, подсказка ядра заменена), запоминаются в сохранении (`app.meta:mark_tutorial_seen`), работают для свайпа и тап-тап.
- Лимиты: пик 185 узлов из 1024 и 434 анимации из 2048 (победа на 14 уровне, `max_nodes` не менял); `app.ui.level` для QA.

## Правки вне моей зоны
- `screens/level/board.script`: четыре вызова охранника (`sent`, `allow_command`, `hint`, `allow_cell`), поведение без охранника прежнее; `link.board_rect()` отдаёт ту же таблицу, пока поле не сдвинулось.
- `tools/qa/web_screens.mjs`: тап по (80, 1160) теперь открывает паузу, скрипт выходит через цель `leave`.
- `client/i18n.lua`: в блоках уровня убраны мёртвые ключи (`popup.level.*`, `hud.win/lost`, `win.coins/stars` и др.), пример в шапке теперь `common.stars`.
