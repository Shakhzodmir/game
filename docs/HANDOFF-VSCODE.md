# GLOW («Город на бис»): полный разбор проекта и передача работы в VS Code

Срез на 06.11.2026. Документ для продюсера, который переносит работу из облачных сессий в VS Code. Всё, что здесь сказано о проверке, проверено; что не проверено, названо отдельно (раздел 7). Если этот документ расходится с `docs/design/decisions.md`, прав `decisions.md`.

## 0. Коротко

**Что это.** Игра «три в ряд» про музыку: каждое совпадение звучит нотой в тональности района, звёзды за уровни восстанавливают город (пять районов-комнат) и включают новые слои песни. Герой, Бит, живёт в городе, пишет песню по ходу прохождения и радуется победам. Движок Defold 1.13.1, портрет 720×1280, сначала HTML5 (браузер), потом мобильные.

**Где она.**
- Репозиторий (публичный): https://github.com/Shakhzodmir/game
- Живая игра: https://shakhzodmir.github.io/game/ (CI сам публикует проверенную сборку в ветку `gh-pages`; сайт обновляется через 5–10 минут после слияния в основную ветку).
- **Основная ветка называется `claude/brave-maxwell-j19fpr`, а не `main`.** Слияние в неё запускает публикацию на сайт.

**В каком состоянии.** Все пять правил-слоёв готовы и на сайте: ядро правил, мета и экономика, город, экран уровня, 100 уровней. Волны 0–4 плана v3 слиты 06.11.2026 (PR #19): сохранение без потерь, магазин, корейский язык, звёзды по очкам, бонус-шкала, музыка комнат, карта, живые комнаты и анимации Бита, песня-блокнот, аккаунты, чарт и группа. В браузере (headless Chromium, реальный движок) полный прогон 138 проверок зелёный; на телефонах и у живых игроков игра ещё не проверялась.

**Что не готово, коротко.** Настоящих картинок в игре пока нет (рисунки от ChatGPT обработаны, но не установлены, раздел 6.4); вход по почте, облако и чарт не работают без проекта Firebase (раздел 9); уровней только 100, а будет больше (план WP-13…17); цены районов не пересчитаны; ждёт ответа несколько вопросов (раздел 8).

## 1. Быстрый старт в VS Code (15 минут)

1. **Клонировать и встать на основную ветку:**
   ```sh
   git clone https://github.com/Shakhzodmir/game.git && cd game
   git checkout claude/brave-maxwell-j19fpr
   ```
   (Если хотите ветку `main`: переименуйте основную ветку в настройках репозитория GitHub, потом поправьте условие публикации в `.github/workflows/ci.yml`, строка `if: github.event_name == 'push' && (...)`. Без этого не делайте.)
2. **Поставить инструменты** (Linux или WSL; на macOS то же через brew):
   - `lua5.1`, `luajit` (тесты идут на обеих виртуальных машинах: Lua 5.1 как в вебе, LuaJIT как на мобильных);
   - `python3` с `numpy pillow scipy soundfile fonttools` (**fonttools обязателен**: без него `tools/gen_defold.py --check` даёт ложное «out of date» для корейских шрифтов; на этом уже споткнулись);
   - `node` + Playwright (только для проверки в браузере);
   - для сборки: JDK 25 и `bob.jar` Defold 1.13.1: https://github.com/defold/defold/releases/download/1.13.1/bob.jar
3. **Проверить, что всё на месте:**
   ```sh
   ./tools/test.sh                 # около 5 минут на двух ВМ, ожидается «2268 passed, 0 failed» на каждой
   ./tools/check_syntax.sh
   luajit tools/check_refs.lua
   luajit tools/levels.lua validate --strict
   python3 tools/gen_defold.py --check
   ```
4. **Собрать и открыть игру:**
   ```sh
   JAVA=/path/to/java BOB=/path/to/bob.jar VARIANT=debug ./tools/build_web.sh
   python3 -m http.server 8791 -d dist/GLOW      # http://localhost:8791/
   ```
   Отладочная сборка: F1 город, F2 уровень, F3 заставка, F5 +1000 монет, F6 язык, F9 сброс сохранения; мост для автотестов (`window.__glowCmd`, `window.__glowState`) только на localhost. `VARIANT=release` без этих средств.
5. **Проверка в браузере** (то, что ловит ошибки, невидимые тестам на заглушках):
   ```sh
   node tools/qa/web_screens.mjs http://localhost:8791/index.html docs/media      # весь прогон ~25 минут
   node tools/qa/web_screens.mjs <url> <dir> --ko-only | --rooms-only | --songbook-only   # части по отдельности
   ```
   Нужен Playwright (`npm i playwright`, один раз `npx playwright install chromium`); путь можно задать `PLAYWRIGHT=/path/to/playwright/index.js`. Выход 1 при ошибке проверки или ошибке Lua в консоли.

## 2. Как устроен проект

```
core/       правила игры, чистый Lua, без Defold: тики, поле, матчи, 4 спецфишки и 10 комбо, Пташка,
            препятствия, бустеры, реплеи и хеш. Детерминированный: один сид = одна и та же партия.
meta/       мета и экономика, чистый Lua: монеты, звёзды, жизни, серия, районы и задачи, сундуки,
            песня-блокнот, аккаунты, чарт и группа (правила), сохранение с версией и суммой.
client/     клиент Defold: app (экраны), bus (шина), save_io, i18n (ru/en/ko), ui, level_* (сессия,
            ввод, анимации, эффекты, звук, HUD), bonus_meter, anim, qa_bridge, services/ (мок-сервисы).
screens/    экраны-коллекции: splash, town (город), level (поле, HUD, окна), map (карта).
gui/        общие окна: старт, магазин, жизни, настройки, автомат (джукбокс), сундук, подарок,
            концерт, блокнот, аккаунт, чарт, группа, окна уровня.
content/    данные: 100 уровней (json), districts, rooms, animations, tutorials, map, stars, genres.
assets/     картинки, звук, шрифты; assets/gen/ создаёт tools/gen_defold.py (руками не править);
            assets/art_ready/ готовые рисунки продюсера после обработки (раздел 6.4).
tools/      тесты, сборка, генераторы арта и звука, уровни и боты, QA-скрипты, очередь рабочих.
tests/      тесты на чистом Lua (около 2268 на каждой ВМ) и строгие заглушки Defold, на которых идут
            настоящие .script и .gui_script.
docs/       журнал решений, правила ядра, мета, архитектура клиента, арт-дирекшн, планы, записки.
```

**Главные правила кода** (нарушать нельзя):
1. Ядро и мета не вызывают Defold и не используют время/случайность вне своих потоков: детерминизм (хеши, реплеи, 8 золотых реплеев в `tests/golden`).
2. **Прогресс игрока не уменьшается.** Формат сохранения расширяется только новыми полями верхнего уровня; есть версия, сумма и резервная копия; есть код сохранения `GLOW1-…` (настройки). Продюсер играет на живом сайте на 89-м уровне.
3. Всё, что можно, проверяется без движка (строгие заглушки Defold). Любое GUI-изменение: тесты на заглушке **и** прогон в браузере.
4. Тексты в одном месте (`client/i18n.lua`, `i18n_ko.lua`, `i18n_songbook.lua`) на ru, en, ko; проверка «текст не вылезает» (`tests/client/layout_audit_test.lua`).
5. Сгенерированное (`assets/gen/`, `client/assets_index.lua`) не править руками: `python3 tools/gen_defold.py`.
6. Не превышать лимиты движка (узлы GUI, спрайты, `gui.max_animation_count` = 2048; эффекты ограничены потолками).

Главные документы по порядку чтения: `README.md` → `docs/STATUS.md` → `docs/design/README.md` (индекс) → `docs/design/decisions.md` (журнал, главный) → `docs/plan-v2.md` (производство, платформы, риски, вопросы Q1–Q12) → `docs/plan-v3.md` (волны 0–4) → `docs/decisions-2026-11-06.md` (последние решения) → `docs/handoff/WP-*.md` (записки по частям).

## 4. Как мы работали (процесс)

**Роли.** Продюсер (вы): решения, играет на живом сайте, даёт «go» на платные задачи. Основная сессия (помощник): разговор с вами, проверка в браузере, слияния, мелкие задачи. Оркестратор: отдельная сессия, которая запускает очередь рабочих (`tools/agents/ORCHESTRATOR.md`). Рабочие: `claude -p` по одному заданию из `tools/agents/tasks/WP-*.md`, каждый в своей ветке `agent/<id>` и рабочей копии; результат сливается в `agent/integration`.

**Поток.** задача в `queue.json` → рабочий → проверки runner-а (тесты на обеих ВМ, линтеры) → слияние в `agent/integration` → `final-check` → проверка в браузере (`web_screens.mjs`, снимки смотрит человек или сессия) → PR в основную ветку → CI (тесты, `gen_defold --check`, сборка `bob`) → слияние squash → CI публикует `gh-pages` → проверка сайта.

**Очередь:** `python3 tools/agents/run_queue.py status | run | stop | reset | final-check | selftest | check-key`, подробно в `tools/agents/README.md`. Ключ рабочих только в переменной окружения `WORKER_API_KEY` (в чат и коммиты ключ не писать). **Только модели Claude Sonnet 5.5 и Claude Haiku 5.5** (решение продюсера; runner не запустит другие). Платный запуск только по слову продюсера.

**Ветки.** Основная: `claude/brave-maxwell-j19fpr`. Рабочая ветка основной сессии `claude/brave-curie-dehte0`: после каждого слитого PR сбрасывалась на голову основной (`git push --force-with-lease`). Ветки рабочих `agent/<id>`, общая `agent/integration`. Оригиналы рисунков продюсера (86 МБ) в ветке `art-incoming`, в основную не входят.

**Обычай продюсера.** Отвечать по-русски и коротко; конкретно: что сделано, что нет; не показывать секреты; ничего непроверенного не сливать в основную ветку (он играет на живом сайте); слияние и публикация разрешены после зелёного CI.

## 5. Решения продюсера (все важные)

- Модели рабочих: только Sonnet 5.5 и Haiku 5.5.
- Звёзды по очкам; концерт = сложный уровень, за него суперзвёзды (WP-4). **Суперзвёзды пока копятся, тратить некуда (продюсер: «подумаем ещё»).**
- 06.11.2026 (`docs/decisions-2026-11-06.md`): **концерт в конце каждого района**; **карта вместо кнопки «Уровень N»** (ответ «да» был двусмысленным; по умолчанию заменяем, уточнить: или оставить обе рядом); районы по 20 уровней подходят; джукбокс как есть (4 жанра открыты с первого дня: Lo-fi, классика, народная, эмбиент; остальные по районам); блокнот: одна строка на уровень, маленькая кнопка без подписи подходит; **пересчитать цены районов, платить монеты за улучшенный повтор**; **уровней будет больше 100, потолка нет**.
- Реальные песни не используются: музыка и арт делаются нашим кодом или присылаются продюсером.

## 6. Важные подробности и подводные камни

**6.1 Тесты и CI.** `./tools/test.sh` гоняет оба движка; CI дополнительно ставит `python3-fonttools` (локально тоже нужен). Падение CI из-за `gen_defold --check` почти всегда значит «не поставлен fontTools» или «забыли перегенерировать». Тесты длинные (около 5 минут): не запускать параллельно с прогоном в браузере (замеры плывут).

**6.2 Проверка в браузере (`tools/qa/web_screens.mjs`).** Прогон 25 минут на программном GL, к нагрузке чувствителен: одиночные «timeout waiting for the start window» бывают, повтор по частям (`--ko-only` и т.д.) обычно проходит. Особенности, о которые споткнулись: `advance N` оставляет к игре уровень N (проиграно N−1); `town_skip` не закрывает окно сундука (тап по `chest`, затем `collect`); команда `close` пропускает предложение готовой песни, реальные тапы нет; после победы город «занят» (награды летят), тап по кнопке блокнота в это время проглатывается; `p.mouse.wheel` в Chromium до игры не доходит (раздел 7).

**6.3 Что умеет и чего не умеет движок.** Defold 1.13.1 в вебе слушает только устаревшие `mousewheel`/`DOMMouseScroll`; современный Chrome шлёт одно `wheel`, поэтому **колесо мыши не работает на карте в настольном Chrome** (код игры исправен, перетаскивание работает). Исправление: маленькая прослойка в `web/engine_template.html` (wheel → mousewheel); не сделано.

**6.4 Арт (ChatGPT → игра).** Рисунки делает продюсер в ChatGPT на ровном розовом фоне #FF00FF по `docs/art-brief-chatgpt.md` (58 картинок; образцы-листы в `docs/media/art-reference/`). `python3 tools/art/import_incoming.py` вырезает фон, режет листы, приводит к размерам и кладёт в `assets/art_ready/<группа>/…` (все 58 картинок обработаны, 201 файл). **Установка в игру не выполнена:** `python3 tools/art/install_ready.py` (ставит готовые кадры под имена игры, ведёт `assets/art_ready/installed.json`, после этого `gen_art.py` их не затирает) ещё не запускалась; 114 файлов готовы, а **30 файлов `deco_*_d1..d6` не ставятся: они 192×192, код ждёт 160×160** (нужно привести в соответствие импортёр или код и поправить бриф). В игре сейчас процедурные заглушки (`tools/art/*.py`). Порядок: поправить размер декораций, `install_ready.py`, `gen_defold.py`, сборка, снимки, посмотреть глазами.

**6.5 Корейский и шрифты.** Шрифты Jua (заголовки, кнопки) и Noto Sans KR Bold (числа, текст). В Jua нет знаков `` ` × ‘ ’ … − ``: если они стоят в тексте, нарисованном шрифтом Jua, на месте знака будет пусто. Какие тексты с `×` и `…` рисуются Jua, не проверено (тексты: награда за серию, магазин, подсказка про птицу, «загрузка…» в чарте и группе).

**6.6 Прочее известное.** Если закрыть окно подарка или сундука командой `close` (кнопка «Назад» на Android делает то же), завершённая песня не предлагается (блокнот остаётся доступен по кнопке). Экономика города не пересчитана под новые правила (бот закрывает город к ~78-му уровню). Тексты ko (блокнот, аккаунты, чарт) переведены без носителя.

## 7. Что не проверено

- Телефоны и планшеты (Android, iOS, мобильный браузер): кадр, память, батарея на слабых устройствах.
- Музыку никто не слушал (проверена измерениями, не на слух), особенно новые жанры (K-pop, рок-баллады, EDM, хип-хоп: часть песен урезана ради размера).
- Корейские тексты не читал носитель.

## 13. Чего не делать

- Не уменьшать прогресс и не менять формат сохранения иначе как новыми полями верхнего уровня.
- Не править руками `assets/gen/` и `client/assets_index.lua`; не слать в игру отладочную сборку (`DEBUG_BUILD_DO_NOT_PUBLISH`).
- Не убивать процессы по шаблону имени (`pkill -f`), только по PID; не писать `sleep`-цепочки в сессиях Claude Code (использовать ожидание по условию).
- Не вставлять ключи, токены, пароли в чат и коммиты.
- Не сливать в основную ветку непроверенное: CI собирает и публикует сайт при каждом слиянии.
- Не запускать платных рабочих без слова продюсера.
