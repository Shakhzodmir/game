# Решения продюсера от 06.11.2026

Ответы на вопросы из записок WP-4, WP-6, WP-7, WP-9, WP-11 после слияния волн 0–4 (PR #19).

| Вопрос | Решение | Что делаем |
|---|---|---|
| Суперзвёзды: на что тратить | **Подумаем ещё.** | Пока копятся и показываются, `C.super_stars.sinks` пуст. Новых задач нет. |
| Концертные уровни | **Концерт в конце каждого района.** | WP-14: концерт = последний уровень района (20, 40, 60, 80, 100 и дальше). Прежние концерты 70, 90 перестают быть концертами; заработанные суперзвёзды остаются. |
| Карта | **Да:** карта вместо кнопки «Уровень N»; районы по 20 уровней подходят. | WP-16 (по умолчанию заменяем кнопку; вернуть рядом можно одной правкой). Если имелось в виду «оставить обе», скажите. |
| Жанры в джукбоксе | **«Как хочешь».** | Оставляем как есть: 4 жанра (Lo-fi, классика, народная, эмбиент) открыты с первого дня, остальные по районам. |
| Блокнот песни | **Да:** одна строка на уровень, маленькая кнопка без подписи подходит. | Без изменений. |
| Цены и повторы | **Да:** пересчитать цены районов; монеты за улучшенный повтор нужны. | WP-15. |
| **Уровней будет больше 100** | **Не ограничиваться 100.** | WP-13: содержимое открытое, новые уровни и районы добавляются данными, без правок кода. WP-17: первая партия, уровни 101–200 и районы 6–10. |
